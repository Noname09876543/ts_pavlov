# Анализ и прогнозирование временного ряда температуры воздуха

## Цель работы

Исследование временного ряда среднесуточной температуры воздуха и построение моделей прогнозирования на основе статистических методов, методов машинного обучения и глубокого обучения.

---

# Описание набора данных

В работе использован набор данных **Daily Climate Time Series Data** для города Дели (Индия).

Временной ряд содержит ежедневные наблюдения за период с 2013 по 2017 год и включает следующие признаки:

* date — дата наблюдения;
* meantemp — средняя температура воздуха;
* humidity — влажность воздуха;
* wind_speed — скорость ветра;
* meanpressure — атмосферное давление.

Целевой переменной является среднесуточная температура воздуха (meantemp).

---

# Постановка задачи

Необходимо провести исследование временного ряда температуры воздуха и разработать пайплайн прогнозирования.

Для достижения цели были поставлены следующие задачи:

1. Провести разведочный анализ данных (EDA).
2. Исследовать статистические методы прогнозирования.
3. Исследовать методы машинного обучения и глубокого обучения.
4. Разработать и протестировать пайплайн прогнозирования.
5. Выполнить сравнительный анализ моделей и выбрать наилучший метод.

---

# Задача №1. Исследование временного ряда

## Предварительный анализ

Была проведена проверка данных на наличие пропусков и дубликатов.

В результате анализа:

* пропуски отсутствуют;
* дубликаты отсутствуют;
* временной ряд содержит ежедневные наблюдения.

## Визуальный анализ

Были построены графики временных рядов:

* средняя температура;
* влажность;
* скорость ветра;
* атмосферное давление.

### Основные наблюдения

* наблюдается выраженная сезонность температуры;
* присутствует долгосрочный тренд;
* в признаке meanpressure обнаружены аномальные значения;
* в признаке wind_speed обнаружены выбросы.

## Анализ выбросов

Для выявления выбросов были построены boxplot-диаграммы.

В результате анализа:

* в признаке meanpressure выявлены аномальные значения;
* в признаке wind_speed обнаружено 33 выброса.

## Корреляционный анализ

Построена корреляционная матрица между признаками.

Корреляционный анализ показал наличие связи между температурой и влажностью, а также умеренную связь температуры с другими климатическими параметрами.

## Автокорреляционный анализ

Для исследования структуры временного ряда были построены графики ACF и PACF.

Анализ показал наличие значимой зависимости между соседними наблюдениями и сезонной составляющей.

## Проверка стационарности

Для проверки стационарности использован тест Дики-Фуллера.

Полученные результаты:

* ADF Statistic = -2.379;
* p-value = 0.148.

Поскольку p-value > 0.05, временной ряд нельзя считать стационарным.

### Вывод по задаче №1

В результате исследования установлено, что временной ряд температуры обладает выраженной сезонностью и не является стационарным. Также были обнаружены выбросы и аномальные значения в дополнительных признаках.

# Задача №2. Исследование статистических методов прогнозирования

В качестве статистических методов были выбраны:

# Задача №3. Исследование методов машинного обучения

## Feature Engineering

Для повышения качества прогнозирования были сформированы дополнительные признаки:

### Календарные признаки

* месяц;
* день недели;
* номер дня в году.

### Лаговые признаки

* lag_1;
* lag_7;
* lag_30.

### Скользящие средние

* rolling mean 7;
* rolling mean 30.

## Исследуемые модели

### Машинное обучение

| Тип | Метод         |
| --- | ------------- |
| ML  | Random Forest |
| ML  | XGBoost       |

### Глубокое обучение

| Тип | Метод  |

| Модель        |  RMSE |

| AutoTheta     | 3.963 |

Использование методов машинного обучения позволило существенно снизить ошибку прогнозирования.

### Вывод по задаче №3

Наиболее эффективной моделью машинного обучения оказался Random Forest, обеспечивший минимальное значение RMSE = 1.636.

# Общее заключение

В ходе работы был исследован набор данных Daily Climate Time Series Data, содержащий ежедневные климатические наблюдения для города Дели.

Проведенный анализ показал наличие сезонности и нестационарности временного ряда температуры.

Было выполнено сравнение статистических методов прогнозирования, методов машинного обучения и методов глубокого обучения.

Среди статистических методов наилучший результат показала модель AutoTheta с RMSE = 3.963.

Среди методов машинного обучения лучшей оказалась модель Random Forest с RMSE = 1.636 и MAE = 1.241.

Полученные результаты показали существенное преимущество методов машинного обучения над классическими статистическими моделями для задачи прогнозирования температуры воздуха.

Разработанный пайплайн может быть использован для дальнейших исследований и решения практических задач прогнозирования временных рядов.
